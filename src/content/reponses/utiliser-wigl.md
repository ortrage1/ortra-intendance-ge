**Où trouver les tutoriels.** Dans votre tableau de bord WIGL, sous **« Moyens auxiliaires WIGL »** :

- **Instructions formateurs/trices** : six cours courts, à commencer par « Introduction », puis « Carte d'entreprise », « Mandats pratiques », « Administration / Profil », « Mes apprentis » et « Rapport de formation » ;
- **WIGLtutorials Apprentis** : les tutoriels pour les apprentis.

## Pour la formatrice ou le formateur

WIGL permet de faire, au même endroit :

1. **Créer et attribuer des mandats pratiques** à l'apprenti, avec une date d'échéance.
2. **Évaluer les mandats réalisés** et vérifier sa documentation d'apprentissage.
3. **Suivre ses progrès** et retrouver ses rapports.
4. **Établir le rapport de formation** de chaque semestre.

**Bien rédiger la consigne d'un mandat.** Dans le champ « Commentaire », séparez ce qu'il faut faire en pratique et ce qu'il faut rédiger. Par exemple :

- **Travail pratique :** nettoyage de contrôle d'une chambre.
- **Travail écrit :**
  1. Faire le travail sur ordinateur ou à la main.
  2. Me le montrer.
  3. Je le corrige.
  4. Vous l'adaptez.
  5. Je le valide.
  6. Vous le transformez en PDF.
  7. Vous le déposez sur WIGL.

## Pour l'apprenti : traiter un mandat dans le portfolio

1. Sur le tableau de bord, cliquez sur **« Afficher toutes les tâches »**.
2. Choisissez le mandat à traiter. Les couleurs indiquent où vous en êtes : **rouge**, en retard ; **orange**, dans les temps ; **vert**, évalué, donc terminé.
3. En bas de la page du mandat, cliquez sur **« Commencer le traitement maintenant »**.
4. Quand le portfolio s'ouvre, cliquez sur **« WIGL Login »**.
5. Cliquez sur le **crayon** pour travailler le mandat. Deux possibilités :
   - remplir les blocs déjà prévus (élaboration, réflexion), en cliquant sur leur crayon ;
   - ajouter votre propre document avec le **« + » violet** : choisissez le type de document, sélectionnez le fichier sur votre ordinateur, puis enregistrez. Vous pouvez ensuite le déplacer avec la flèche.
6. Une fois le travail terminé, cliquez sur **« Soumettre le portefeuille »**. Votre formatrice ou votre formateur peut alors l'évaluer.
